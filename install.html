Nomad Workbench 自行安裝說明

約 30 分鐘。全程在貴公司自己的 Google 帳號中操作，系統供應商看不到你的任何資料。

開始前請準備

  • 一個 Google 帳號：之後所有單據、證件影像都會存在這個帳號的雲端硬碟。建議用公司的 Google Workspace 帳號（例如 admin@貴公司網域）；個人 Gmail 也可以。
  • 授權金鑰 Email：在下方表單申請免費試用，或購買後，你會收到一封來自 REMON nomad 的信，裡面有授權金鑰、「建立副本」按鈕和這份安裝說明的連結。沒收到的話，請看一下垃圾郵件匣。
  • 用電腦操作，建議使用 Chrome，並只登入這一個 Google 帳號（多帳號同時登入容易出錯）。
安裝過程中，試算表的「安裝精靈」會自動檢查每一步，做錯會告訴你哪裡要改。卡住了也可以請我們代裝。

  2. 設定 OAuth 同意畫面

免費試用 180 天

填寫後，試用金鑰會立即寄到你的信箱。試用 180 天，往來、帳務、勞報單三個模組全開（勞報單每月可發送 20 張），資料一樣存放在你自己的 Google 帳號。

Email 請填之後要用來安裝系統的 Google 帳號信箱，或你常用的信箱。

1

建立 Google Cloud 專案並啟用 API

系統需要一個屬於你自己的 Google Cloud 專案，才能自動接收新版本與法規參數。不需要付費，也不用綁信用卡。請用之後要存放資料的那個 Google 帳號登入。

  1. 開啟 建立專案。專案名稱只能用英文、數字和連字號，例如 nwb-acme，按「建立」。
  2. 開啟 一次啟用 4 個 API。上方確認選的是剛建立的專案，按「下一步」→「啟用」。會啟用 Apps Script、Drive、Sheets、Docs 這 4 個 API。
2

設定 OAuth 同意畫面

開啟 OAuth 同意畫面，按「開始」，依你的帳號類型填寫：

公司 Workspace 帳號個人 Gmail
目標對象內部外部
應用程式名稱Nomad Workbench（也可以用縮寫 NWB）
使用者支援 Email、聯絡資訊你自己的 Email

個人 Gmail 還要多做兩件事：

  1. 在「品牌」頁填入下列網址，不要上傳標誌（上傳標誌會需要 Google 審查）：
    應用程式首頁https://hanslintw.github.io/
    隱私權政策https://hanslintw.github.io/privacy.html
    服務條款https://hanslintw.github.io/terms.html
    授權網域hanslintw.github.io
  2. 到「目標對象」按「發布應用程式」，切換為「正式版」。不切換的話，授權每 7 天就會失效。
3

記下專案編號

開啟 Cloud 主控台首頁，確認上方選的是剛建立的專案，在「專案資訊」找到「專案編號」並複製。

專案編號是一串數字（例如 123456789012），不是英文的專案 ID。先把它貼到記事本，下一步會用到。Google Cloud 的設定到這裡就完成了。
4

建立副本，並連結 Cloud 專案

  1. 點授權金鑰 Email 裡的「建立副本」按鈕，再按 Google 畫面上的「建立副本」。系統程式會一起複製到你的雲端硬碟。試算表內容先不用動。
  2. 在剛建立的試算表上方選「擴充功能 › Apps Script」。
  3. Apps Script 左側點齒輪「專案設定」→ 往下找到「Google Cloud Platform (GCP) 專案」→「變更專案」，貼上步驟 3 記下的專案編號，按「設定專案」。

這個 Apps Script 分頁請先保留，步驟 7 部署時會再用到。

5

開啟 Apps Script API

開啟 Apps Script 使用者設定，把「Google Apps Script API」切換為「開啟」。

6

開啟安裝精靈，建立資料庫

  1. 回到試算表，重新整理頁面，上方會出現「Nomad Workbench」選單。選「Nomad Workbench › 安裝精靈」。
  2. Google 會要求授權：選你的帳號 → 若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往 Nomad Workbench（不安全）」→ 勾選全部權限 →「繼續」。
  3. 右側的安裝精靈會檢查前面的步驟。前面幾項都打勾後，在「建立資料庫與資料夾」按「建立」。精靈最上方的「重新檢查」按鈕隨時可以按。
為什麼會顯示「尚未驗證」？因為這個程式是複製到你自己帳號裡執行的，Google 把它視為你自己寫的程式，所以不會經過 Google 審查。資料只在你的帳號裡流動，不會送到第三方。系統使用的權限與用途，請見隱私權政策。
7

部署兩個網頁

回到步驟 4 的 Apps Script 分頁（若已關掉，從試算表「擴充功能 › Apps Script」再開一次），右上角「部署 › 新增部署」，在「選取類型」旁的齒輪選「網頁應用程式」。這個動作做兩次：

說明執行身分具有存取權的使用者
第 1 個所得人填寫頁我所有人
第 2 個企業後台我網域內的使用者
個人 Gmail 選「擁有 Google 帳戶的使用者」

兩個都部署好後，回到安裝精靈，按「部署兩個網頁」這一步裡的「重新檢查」（精靈最上方也有一顆）。精靈會自動找到兩個網址並填入設定，不用自己複製貼上。

「執行身分」兩個都要選「我」。如果選成「存取網頁應用程式的使用者」，所得人會無法開啟填寫頁。
8

輸入授權金鑰，完成

在安裝精靈最後一步貼上金鑰，按「驗證並啟用」。全部打勾後按「開啟企業後台」，建議把後台網址加入瀏覽器書籤。

接著到後台「設定 › 成員與權限」加入經辦與財務人員，到「設定 › 公司資料」填好公司名稱、統一編號等資料，就可以開始開單。

之後有新版本時，管理員會在後台看到提示，按一下就能完成更新。資料不會受影響。

常見問題

為什麼一定要建立 Google Cloud 專案？
系統要靠它安全地更新你帳號裡的程式。法規參數（例如健保費率）調整或功能更新時，你只要在後台按一下更新，不用重新安裝。

精靈說「需要重新同意權限」？
連結 Cloud 專案後，Google 會要求重新授權，這是正常的。關閉側邊欄，從選單重新開啟安裝精靈即可。

「開啟 Apps Script API」之後還是顯示沒開？
這個設定約需 1–5 分鐘才會生效，稍等再按「重新檢查」。

系統供應商看得到我的資料嗎？
看不到。所有資料都存在你自己的 Google 帳號，授權中心只會收到每月張數這類統計數字，詳見隱私權政策。
